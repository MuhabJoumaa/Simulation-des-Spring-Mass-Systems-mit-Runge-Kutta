# Simulation-des-Spring-Mass-Systems-mit-Runge-Kutta
A program that numerically solves the differential equation of a spring–mass system using the fourth-order Runge–Kutta (RK4) method.
The program calculates the object's position over time based on the initial position, initial velocity, mass, and spring constant. It uses NumPy for numerical calculations and Matplotlib to visualize the motion.

There are two versions of the program; one was written in Python and one in Maple.

Differential equation:
[
$$
\frac{d^2x}{dt^2} = -\frac{k}{m}x
$$
]
